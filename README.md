# Andrei.Dev — Portofoliu Web Developer & Arhitect AI

Site-ul de prezentare și generare clienți pentru serviciile de dezvoltare web, integrări MCP și aplicații digitale oferite de Andrei. Include un estimator interactiv de buget & timp de execuție și showcase al proiectelor realizate.

## Cum rulezi proiectul
- **Vizualizare Imediată:** Fă dublu-click pe `index.html` pentru a deschide site-ul în browser.
- **Hosting Live:** Încarcă fișierele (`index.html`, `styles.css`, `app.js`) pe Cloudflare Pages sau Vercel.
- **Next.js:** Fișierul `page.tsx` este disponibil pentru utilizare în Next.js.
